# Zenodo Data 2 structure archive

Data 2 is deposited as eleven standard ZIP files, supplementary_data_structure_part01.zip through supplementary_data_structure_part11.zip. Download all eleven and extract all of them into the same new directory. Each is a normal ZIP archive. No binary concatenation is needed. Then follow the extracted README.txt for portable replay commands and dependencies.

All 122 file payloads match the qualified master supplementary_data_structure.zip exactly, including names, sizes and SHA-256 values. Every payload in every part was read and hashed before deposit. These are the retained, already prepared upload parts. No simulation or scientific analysis was rerun to create this deposit.

The full single-ZIP form remains available with Data 1 and the original versioned code at https://github.com/redeem123/CuTa-Paper3-Data/releases/tag/paper3-v2.0-common-wait . PARTS_MANIFEST.json records exact ZIP-part hashes. The master archive has SHA-256 ed35ab54ba089e59701d4518f12258d4e19b18bb61e2ad895ff16e61379f2e5d . Individual ZIP parts have their own hashes and must not be compared with the master ZIP hash.

Data 1 is supplementary_data_mechanics.zip and is extracted into a separate directory. Do not extract Data 1 into the Data 2 directory.
